## Purpose SQL Practice

A collection of MySQL queries written while practicing and strengthening core SQL concepts — from basic filtering to more advanced joins, subqueries, and window functions.

Purpose

This repo is a personal practice log, not a production project. It's meant to demonstrate hands-on familiarity with SQL fundamentals that come up regularly in backend development — writing efficient queries, working with relational data, and understanding how different query types solve different problems.

Tech
Database: MySQL
Tools: MySQL Workbench
Topics Covered
SELECT, WHERE, ORDER BY, GROUP BY, HAVING
Joins — INNER JOIN, LEFT JOIN, RIGHT JOIN, self joins
Subqueries — correlated and non-correlated
Aggregate functions — COUNT, SUM, AVG, MIN, MAX
Window functions — ROW_NUMBER(), RANK(), DENSE_RANK(), partitioning
Common Table Expressions (CTEs)
DDL — CREATE TABLE, ALTER TABLE, constraints, foreign keys
DML — INSERT, UPDATE, DELETE
Structure

Queries are organized as flat .sql files, generally grouped by the concept being practiced (e.g. joins, subqueries, aggregations). File names indicate the topic covered.

How to Use
Clone the repo:
bash
   git clone https://github.com/Sujayjk123/<repo-name>.git
Open any .sql file in MySQL Workbench (or your preferred client).
Run against a local MySQL instance — most queries assume standard sample datasets (e.g. employees, orders, students) which may need to be created first depending on the file.
Note

This is an ongoing practice repo and will be updated as new concepts are covered.
